# 智能分析平台 — 项目背景

**全栈开发实习生 | 广东省智能科学与技术研究院 金融工商智能实验室 数据平台组**

## 平台概况

金融工商智能实验室数据平台组负责实验室两大核心数据库系统的维护，并在此基础上构建 Data Agent，通过 AI 驱动的自然语言交互降低非技术研究人员的数据使用门槛。

---

### 一、金融经济数据库（200+ 张表，约 1,000 万行，~10 GB）

按研究主题划分为三大域：

#### 主题一：绿色经济（~40 张表）

聚焦可持续发展与碳中和研究，下设三个子库：

- **自然资源**：土地资源（土地利用类型、耕地面积变动）、水资源（流域水质、用水量）、海洋资源（海域使用、海洋经济产值）、气候数据（气温、降水、极端天气事件）
- **全球暖化**：空气污染（各城市 PM2.5/PM10/NO₂/SO₂ 日均浓度）、空气质量指数（AQI）历史序列、碳排放权交易（各试点市场碳配额价格与成交量）
- **绿色金融**：绿色信贷（银行绿色贷款余额与投向行业分布）、绿色债券（发行规模、期限、募集资金用途）、ESG 评级数据

**特色**：将环境微观数据与金融数据打通，支持"碳排放权价格波动 → 高碳行业公司估值影响"等跨域分析。

#### 主题二：公司研究（~100 张表）

覆盖 A 股上市公司全维度画像，下设五个子库：

- **财务数据**：三大报表（资产负债表、利润表、现金流量表，季频/年频）、财务指标衍生（ROE、ROA、毛利率、杠杆率等）
- **股权与治理**：股本结构、前十大股东、董监高任职与薪酬、内部控制评价、审计意见
- **融资与分配**：IPO 明细、增发/配股、分红预案与实施、股权激励计划
- **重大事件**：关联交易、并购重组、股票回购、股票质押、融资租赁、诉讼仲裁
- **特色专题**：分析师盈利预测（一致预期与个体偏差）、内部人交易（董监高增减持明细）

**特色**：将传统财务数据与内部人行为、分析师预期打通，支持"高管减持前的异常信息环境"等行为金融研究。

#### 主题三：经济研究（~60 张表）

覆盖宏观经济运行与区域差异分析，下设三个子库：

- **中国宏观经济**：GDP 与分行业增加值、货币供应量（M0/M1/M2）、利率与汇率、CPI/PPI、就业与工资
- **中国地区经济**：省级/地市级 GDP、财政收入与支出、固定资产投资、居民可支配收入、常住人口
- **中国特色专题**：进出口统计（HS 编码分类、贸易伙伴国）、工业行业统计（分行业产值与利润）、税收数据（分税种、分地区）

**特色**：地区经济数据细化到地市级，支持"地方财政压力 → 辖区内上市公司税收负担"等微观-宏观衔接研究。

---

### 二、行为实验数据库（~26 张表，约 6 万行，~0.3 GB）

存储实验室被试的全生命周期数据，覆盖被试招募 → 实验参与 → 心理测量全流程，按三大域组织：

- **被试域（2 张表）**：被试基本信息（脱敏后的年龄、性别）与被试扩展信息（学历、专业背景、被试标签），一行对应一名被试
- **实验域（3 张表）**：实验定义（名称、类型、设计说明）、实验场次与分组安排（场次时间、参数配置、分组方案）、被试-场次关联表（记录每位被试参与过哪些实验的哪些场次及角色分配）
- **量表域（~21 张表）**：量表定义表 + 按量表类型独立建表（如风险态度、自我效能感、MBTI、大五人格、PANAS 正负情绪等），每张表以被试为行、子问题为列，存储题目级得分

覆盖 3,000+ 被试、150+ 场实验、20+ 套标准化心理学量表。

## Data Agent

Data Agent 是由金融工商智能实验室自主研发的 AI 驱动数据分析系统。基于业务语义层实现智能问数与深度分析，端到端耗时约 15s，覆盖 200+ 数据表及千万级数据，服务来自多所高校与科研机构的 500+ 名研究人员与实验助理，日均查询约 150 次。

**本人职责**：

**智能问数体验优化**（技术栈：Java / Spring Boot / LangChain4j / BGE Embedding / LLM）：
- LLM 语义映射优化：原 SchemaMapper 基于 BGE-M3 Embedding 向量匹配与多层规则过滤，难以区分语义相近但业务含义不同的候选（如"净利润"vs"扣非净利润"）。引入 LLM 对向量粗召回的候选集做语义消歧精选，映射准确率从 58% 提升至 81%。
- 查询记忆复用：将 LLM 自动评审通过的历史成功 SQL 存入向量库作为 Few-shot 样本，新查询召回相似历史注入 S2SQL 生成的 LLM prompt，引入人工审核兜底确保记忆库质量。记忆库累计 800+ 条，端到端查询准确率从 72% 提升至 87%。
- 推荐问题：双通道——行为实验助理高频运维题靠相似推荐少打字（贡献日均查询约 11%）；绿色金融等以内置题引导研究开口（贡献日均查询 15%）。两条均为查询归因占比（`source`/总查询），非曝光点击率。

**问数结果深度研究**（技术栈：Python / asyncio / MCP / Multi-Agent / RAG / Hybrid Search / FastAPI）：
- 问数结果双层解读：智能问数查询结果默认经 LLM 生成描述性解读（结构化摘要 + 关键指标解释）；深度研究作为可选项，对结果做多步联网交叉验证与归因分析，失败则静默回退描述性解读，不阻断查数主链路。
- Main–Sub Agent 编排：主智能体负责任务拆解与结论汇总，将子任务委派给独立会话中的子智能体并发执行，子会话隔离避免上下文膨胀，子智能体回传结构化报告后主智能体汇总输出。在 GAIA-165 评测集中实现 53% 准确率（SOTA：80%）。
- 检索与工具调用：Hybrid Search 基于规则路由与加权融合，对接实验室自有知识库与联网搜索。工具侧基于 MCP 协议统一注册、发现、调用与降级，工具调用成功率达 98%。支撑金融经济场景的行业研报生成与政策归因，以及行为科学场景的相似研究检索与结论校验。
- 工程化能力：全链路结构化追踪确保关键中间结果落盘可复盘，支撑基于日志扫描的断点续跑；可配并发控制实现单任务异常隔离，配合轮次与工具调用数上限的熔断限流保障系统稳定性。

**问数质量评测**：设计测试用例生成 Agent，基于语义模型自动组合生成跨主题域、跨难度的测试用例，经人工抽检校正后作为回归评测集。每次 SchemaMapper 迭代自动跑全量评测并输出混淆矩阵，将评测从手工 2 天/轮缩短至自动 5 分钟/轮，支撑每周 2-3 次快速迭代。
